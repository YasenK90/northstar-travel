# NORTHSTAR — Travel Planning Website

An editorial travel-planning concept with a dark night-sky expedition aesthetic — destination discovery, category/search filters, a saved-trip drawer, destination detail dialogs, and a copyable trip summary. The destinations and copy are a fictional portfolio demo; it does not book travel.

## Live demo

Deployed via GitHub Pages: https://yasenk90.github.io/northstar-travel/

## Run locally

```bash
npm install
npm run dev
```

Vite prints the local URL, normally `http://localhost:5173/`.

## Features

- Responsive desktop, tablet, and phone layouts (including 320px widths)
- Destination category filtering and text search
- Add/remove destinations from a trip, saved locally in the browser
- Destination details dialog
- Trip drawer and copyable trip summary
- Touch-friendly mobile navigation and reduced-motion support

## Notes

Destination photography loads from Unsplash and Google Fonts provides the typography, so those external assets require an internet connection. Saved places use browser local storage. No sign-in, booking, or payments are connected.
